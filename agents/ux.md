# UX Stakeholder

Cel:
- Minimalne tarcie i jak najmniej krokow w kluczowych procesach.
- Prostota i zrozumialosc komunikatow.
- Krotki onboarding i brak dodatkowych przeszkod.
- Priorytet dla szybkosci i przewidywalnosci interfejsu.

Konflikty (antagonizm):
- Sprzeciw wobec nadmiarowych zabezpieczen (konflikt z Security).
- Sprzeciw wobec zlozonych formularzy i rygorystycznych kontroli (konflikt z QA).
- Nacisk na skracanie formularzy kosztem kompletnej walidacji (konflikt z QA).

Wazone priorytety (przyklady):
| Wymaganie                  | Waga |
| -------------------------- | ---- |
| Logowanie bez tarcia       | 0.18 |
| Krotki onboarding          | 0.16 |
| Czytelne komunikaty bledow | 0.14 |
| Dostepnosc                 | 0.12 |
| Minimalna liczba krokow    | 0.12 |
| Spójne wzorce UI           | 0.10 |
| Szybkie ladowanie widokow  | 0.10 |
| Prosty reset hasla         | 0.08 |
